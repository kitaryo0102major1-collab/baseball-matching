## 2. 用語とルール
- **打席結果**: 単打・二塁打・三塁打・本塁打／ゴロ・フライ・ライナー・ファウルフライ（アウト）／三振（空振り・見逃し・振り逃げ）／四球・敬遠・死球／犠打・犠飛／野選・失策出塁／打撃妨害・走塁妨害／併殺・三重殺
- **打球方向**: 守備位置1〜9＋グラウンド図の座標（x, y）。アウトは処理した守備者の並び（例「6-3」）も保存
- **走者の動き**: 打席ごとに「誰が・どの塁から・どこへ（進塁/得点/アウト）・理由（打球/盗塁/盗塁死/暴投/捕逸/ボーク/失策/牽制死/走塁死）」。打席の間の盗塁・暴投なども記録できる
- **自動推定**: 結果を選ぶと標準的な走者の動きと打点を予想して表示（例: 単打なら走者は1つ進む）。違えば直す
- **自責点**: 失策・捕逸が絡んだ得点は自動で「自責なし」と予想し、手で直せる
- **投手の勝敗・S**: 得点経過から候補を自動で出し、確定時に手で選び直せる
- **試合の状態**: 入力中／確定。**成績の集計は確定した試合のみ**
- **打率などの計算式**
  - 打率＝安打÷打数、出塁率＝(安打＋四球＋死球)÷(打数＋四球＋死球＋犠飛)、長打率＝塁打÷打数、OPS＝出塁率＋長打率
  - 得点圏打率＝走者二・三塁時の安打÷打数、対左右＝相手投手の左右別の打率
  - 防御率＝自責点×N÷投球回、WHIP＝(被安打＋与四球)÷投球回、奪三振率＝奪三振×N÷投球回、与四球率＝与四球×N÷投球回（N＝チーム設定のイニング数、初期7）
  - 投球回はアウト数で保存し「5 1/3」と表示
  - 勝率＝勝÷(勝＋敗)（引き分けは除く）

| /mypage/games/new | 試合の作成（日付・相手・場所・種類・大会名・先攻/後攻・予定イニング・守備記録方式・打順人数・DH） |

### 公開ページ（成績を公開しているチームのみ）
- /teams/[id]/games、/teams/[id]/games/[gameId]、/teams/[id]/stats、/teams/[id]/players/[playerId]
- 選手名は表示名のみ。チームページに「成績」欄（チーム成績＋ランキング上位）

### 実力が近いチーム
- 対象: 成績を公開している、同じレベルのチーム（今年度3試合以上）
- 近さ: 勝率の差が小さい順。同じ都道府県（市区町村）を先に
- チームホームに最大3チーム、チーム一覧に「実力が近い順」の並び替え（ログイン中・自チームが成績公開のときだけ）

### シェア画像
- 試合結果（スコアボード）と、選手の年度成績のカード。サイト名とURL入り
- 公開チームはページへのリンク付きでXに投稿、非公開チームも画像の保存は可

### 募集との連携
- マイページ・チームホームの「決定済み・試合日を過ぎた対戦募集」に「この試合の結果を記録する」→ 日付・場所・相手を引き継ぐ
- 相手が登録チームなら、相手のチームホームに「◯◯が試合結果を登録しました」＋「この結果から記録を作る」（得点を反転して引き継ぐ）
- 両チームの最終得点が食い違うとき、両方のスコアページに注意表示（どちらかを正にはしない）

### 過去データの取り込み
- テンプレートCSV（年度・選手名・背番号・打撃合計・投手合計）をダウンロードして記入→アップロード→プレビュー→取り込み
- 年度・通算の基本成績に含める（得点圏・対左右・打球方向は対象外、「取り込み」と注記）

## 4. 入力のしやすさの要件
- 片手で押せるボタン（タップ領域44px以上）、1打席は最短2タップ（結果＋確定）で記録可能
- 直前の打席の取り消し、あとから任意の打席を修正・挿入・削除
- 電波が弱い球場を想定し、入力は端末に自動保存し、つながったら送信（同時に2人で入力したときは後の保存を優先し警告）
- アウトカウント・塁上の走者・得点を常に画面上部に表示

## 5. データ（概要）
- teams 追加: stats_public, innings_per_game(7), qualify_pa_rate(2.0), qualify_ip_rate(1.0), season_start_month(1)
- players: team_id, real_name, display_name, number, throws, bats, positions[], is_helper, active
- games: team_id, game_date, game_type, tournament_name, opponent_name, opponent_team_id, source_post_id, venue, batting_first, scheduled_innings, end_reason, forfeit_result, defense_mode('summary'|'detailed'), lineup_size, use_dh, opponent_innings int[], status('入力中'|'確定'), memo
- game_lineups: game_id, player_id, batting_slot, position, entry_type（先発/代打/代走/守備/再出場/臨時代走/臨時代打）, entered_at（何打席目から）
- plate_appearances: game_id, seq, inning, is_offense, batter_player_id / opponent_batting_slot, our_pitcher_id, opp_pitcher_throws, result, fielders, direction_pos, direction_x, direction_y, rbi, outs_on_play, runners_before（塁状況）
- runner_events: game_id, plate_appearance_id null可, seq, runner_player_id / opponent_slot, from_base, to_base('2'|'3'|'H'|'OUT'), reason, earned boolean
- pitching_summaries（合計モード用）: game_id, player_id, outs, bf, h, r, er, bb, hbp, so, hr
- pitching_decisions: game_id, player_id, decision('W'|'L'|'S'|'H')
- player_season_imports: team_id, player_id, year, 打撃・投手の合計
- RLS: 書き込みはチームの管理者のみ。読み取りは管理者、または stats_public のチームなら誰でも（real_name は公開しない）

## 6. 段階と公開
- **段階①（記録できる）**: DB、名簿、試合作成（ゲスト・チーム）、打順・交代、打席入力（攻撃・守備）、スコアページと確定、基本成績、入口とスコアタブ、ゲスト試合の取り込み。続けてSEO（紹介ページ・計算ツール・ガイド）
- **段階②（深める）**: 詳細指標・規定・期間、個人ページ（分布図）、ランキング
- **段階③（広げる）**: 公開ページ（とそのSEO）、実力が近いチーム、シェア画像、募集との連携、CSV取り込み

## 7. ゲストのスコア（ログインなし）
### できること・できないこと
| | ゲスト | 登録チーム |
|---|---|---|
| 1試合の記録（打順・交代・打席入力・守備・確定） | ◯ | ◯ |
| スコアページ・シェア画像・リンク共有 | ◯ | ◯ |
| 選手名簿（毎回選ぶだけ） | ×（試合ごとに名前を入力） | ◯ |
| 複数試合の通算成績・個人ページ・ランキング | × | ◯ |
| 成績の公開・実力が近いチーム・募集との連携 | × | ◯ |

### 保存と権限
- 試合はサーバーに保存（games.team_id は null）。作成時に推測できない**編集用トークン**を発行し、DBにはハッシュだけ保存
- 編集できるのは、作った端末（トークンを localStorage に保存）と、**編集用リンク**（/scores/[id]/edit#token）を持つ人。共同入力も編集用リンクで可能
- 書き込みはトークンを確認する関数経由のみ（security definer）。RLSの直接書き込みは不可
- **閲覧用リンク**（/scores/[id]）は誰でも見られる。検索結果には出さない（noindex）
- 作った端末の一覧: /scores（「この端末で記録した試合」）。端末を変えたら編集用リンクで開く
- 選手は試合ごとの名前（game_lineups.guest_name）。投打は任意
- 荒らし・放置対策: 同じ端末からの作成数に上限（1日10試合）。チームに取り込まれず1年更新のない試合は削除

### チーム登録への案内（5か所）
1. **打順の名前を入れるとき**:「チーム登録すると名簿から選べて、毎回入力しなくて済みます」
2. **スコア入力が終わったとき**（最終回の3アウト・試合終了を押したとき）:「お疲れさまでした！チーム登録すると、この試合を成績として残せます」
3. **試合を確定したとき**:「この試合をチームの成績として残しましょう」＋「Googleでチーム登録（無料）」
4. **2試合目を記録するとき**:「チーム登録すると、2試合分の通算成績が見られます」
5. **スコアページとシェア画像**:「草野球マッチで無料でスコアをつけられます」（見た人向け。ページ下部とシェア画像の隅）
- どれも閉じられる控えめな表示にし、入力の邪魔をしない（試合中の入力画面ではバナーを出さない）

### チームへの取り込み
- ログインしてチームを登録（または選択）すると、「この端末で記録した試合」を一覧表示し、取り込む試合を選べる
- 取り込みでは打順の名前を名簿の選手に対応づける（同じ名前があれば自動で候補、なければ名簿に新規追加、助っ人として追加も選べる）
- 取り込んだ試合は team_id が付き、チームの試合として通算成績に入る。閲覧用リンクはそのまま使える（チームが成績非公開なら、閲覧用リンクも見られなくなることを取り込み前に表示）
- 編集用リンクから開いた別の端末でも、ログインしてトークンを持っていれば取り込める

### 入口
- 未ログイン: トップの「募集する」「募集を探す」の下に「スコアをつける（登録不要）」、ヘッダーにも「スコア」
- ログイン中: 下部タブ「スコア」（チームの試合一覧）。ゲストで記録した試合が端末にあれば「取り込めます」と表示

## 8. SEO（スコア機能）
### 狙う検索ワード
- 道具を探す人: 「草野球 スコアブック アプリ 無料」「野球 スコア 記録 アプリ」「スコアブック 無料 web」「野球 成績管理 チーム 無料」
- 計算したい人: 「打率 計算」「防御率 計算 7回」「OPS 計算」「出塁率 計算」
- 書き方を知りたい人: 「スコアブック 書き方」「スコアブック 記号 一覧」「野球 自責点 とは」
- チーム名・選手名で探す人: 公開チームの成績ページ

### 技術面
- 各ページに固有のタイトル・説明文・canonical（既存の lib/seo.ts を使う）
- 構造化データ（JSON-LD）: 紹介ページに WebApplication（無料・登録不要）と FAQPage、計算ツールに WebApplication、ガイドに Article と BreadcrumbList、公開試合に SportsEvent（日付・場所・両チーム・スコア）
- OGP画像: 紹介ページ・ツール・ガイドは専用画像、公開試合はスコアボード画像（シェア画像と共通）
- sitemap: 紹介ページ・ツール・ガイド・公開チームの試合/成績ページを追加。ゲスト試合と非公開は入れない
- 内部リンク: トップ・フッター・チームページ・募集詳細（試合が決まった募集）から紹介ページへ。ツールとガイドは相互リンク
- 表示速度: 紹介ページ・ツール・ガイドは事前に作っておく静的ページにし、入力用の重いJavaScriptを読み込まない
- 測定: Search Console で検索ワードと表示回数を確認（手作業）
